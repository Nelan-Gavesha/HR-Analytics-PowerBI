# 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview

The **HR Analytics Dashboard** is an interactive data visualization project developed using Microsoft Power BI. The dashboard provides insights into employee attrition and workforce trends, helping organizations understand employee turnover and analyze workforce-related factors.

The project transforms HR data into meaningful visual insights through interactive charts, KPI cards, and filtering options.

## 🎯 Project Objectives

- Analyze employee attrition patterns.
- Understand attrition across different departments.
- Explore employee attrition by age group and gender.
- Investigate the relationship between overtime and employee attrition.
- Analyze average job satisfaction across departments.
- Provide an interactive dashboard for HR-related decision-making.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation.
- **DAX** – Calculated measures and KPI analysis.

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Attrition Count
- Attrition Rate
- Active Employees

### 2. Employee Attrition Analysis
- Department-wise employee attrition.
- Attrition trends across different age groups.
- Gender-based attrition analysis.
- Overtime-based attrition analysis.

### 3. Job Satisfaction Analysis
- Average job satisfaction across departments.

### 4. Interactive Filters
Users can explore the dashboard using filters for:
- Department
- Gender
- Overtime
- Age Group

## 📊 Key Insights

The dashboard enables HR professionals to:

- Identify departments experiencing higher employee attrition.
- Understand which age groups are more affected by employee turnover.
- Explore gender-based attrition patterns.
- Investigate how overtime relates to employee attrition.
- Compare job satisfaction across departments.
